01. Introducción

En este sitio web presento la resolución analítica y fundamentada del cuestionario correspondiente al trabajo práctico audiovisual. Se detallan los conceptos informáticos fundamentales, la arquitectura del código web y el proceso paso a paso para desplegar un proyecto real desde un entorno local hacia la nube.

02. Conceptos Fundamentales

Estructura HTML5 Semántica

Uso de etiquetas como header, nav, main y section para dar orden lógico y accesible al contenido.

Hojas de Estilo CSS3

Diseño visual mediante reglas de color, tipografía, bordes y gradientes modernos.

Control de Versiones (Git/GitHub)

Almacenamiento y gestión de archivos de código fuente en la nube mediante repositorios públicos.

Despliegue Continuo (Render)

Publicación automatizada que convierte código en un sitio web en vivo al vincular un repositorio.

Diseño Responsivo (Mobile First)

Adaptación automática de la interfaz a diferentes pantallas usando Media Queries y CSS Flexbox/Grid.

03. Cuestionario Analítico Resuelto

Q1

¿Cuál es el tema principal del video? Explica de qué trata.

El tema principal es la maquetación y el desarrollo de interfaces web utilizando estándares modernos de HTML5 y CSS3, culminando con el proceso de alojamiento en servidores públicos de la nube.

Q2

¿Qué problema o necesidad tecnológica se aborda?

Se aborda la falta de conocimiento práctico al estructurar código limpio y la barrera técnica para publicar un proyecto local en internet de forma gratuita, segura y sin servidores propios.

Q3

¿Cuáles son los cinco conceptos más importantes? Define cada uno.

1. Sintaxis: Conjunto de reglas para escribir código comprensible por el navegador.
2. Repositorio: Espacio de almacenamiento en GitHub donde se guardan las versiones del código.
3. Sitio Estático: Página web compuesta por archivos directos (HTML, CSS, JS) sin procesamiento complejo de backend.
4. URL Pública: Dirección web única que permite el acceso global sin requerir inicio de sesión.
5. Media Queries: Reglas CSS que permiten adaptar el diseño según el tamaño de la pantalla.

Q4

¿Qué herramientas, programas o tecnologías se mencionan y para qué sirven?

Se utiliza **Visual Studio Code** para la edición y maquetación de archivos `.html` y `.css`, **GitHub** para la gestión y carga de archivos en la nube, y plataformas de hosting como **Render** y **Netlify** para realizar el despliegue web.

Q5

¿Qué procedimientos o pasos se explican? Preséntalos en orden.

1. Creación local de los archivos `index.html` y `estilos.css`.
2. Creación de un repositorio público en GitHub mediante la opción New Repository.
3. Carga e integración de archivos usando la herramienta Uploading an existing file.
4. Confirmación de guardado con la opción Commit changes.
5. Vinculación de GitHub con la plataforma Render mediante la opción Static Site para generar el enlace final.

Q6

¿Qué ejemplos prácticos aparecen? Explica uno detalladamente.

Un ejemplo destacado es la vinculación en tiempo real entre GitHub y Render. Al conectar el repositorio `tareasol2bti`, la plataforma Render clona automáticamente el código del repositorio, procesa los archivos en un contenedor en la nube y genera una URL funcional en cuestión de segundos.

Q7

¿Qué conocimientos previos son necesarios para comprender lo explicado?

Nociones de estructura de archivos y carpetas en un sistema operativo, sintaxis básica de marcado de texto en HTML, propiedades básicas de estilos CSS y manejo de cuentas de usuario en plataformas web.

Q8

¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?

Permite una publicación rápida, elimina costos de servidor, garantiza que el sitio esté disponible 24/7 y permite la actualización instantánea del sitio web con solo subir una nueva versión del archivo a GitHub.

Q9

¿Qué dificultades, errores o precauciones deben considerarse?

Se debe tener cuidado con nombrar el archivo principal exactamente como `index.html` (en minúsculas), verificar que la ruta del enlace `` coincida con el nombre exacto del archivo CSS y confirmar que el repositorio de GitHub sea **público**.

Q10

¿Cómo aplicarías lo aprendido en un proyecto informático real?

Aplicando este mismo flujo de trabajo (VS Code + GitHub + Render) para la entrega de proyectos del colegio, la creación de portafolios web personales o la maquetación de proyectos web institucionales.

Q11

¿Qué parte del video consideras más importante y por qué?

La etapa del despliegue en la nube, ya que integra la fase conceptual con la parte práctica, permitiendo comprobar que un sitio web funciona de forma accesible para cualquier usuario en internet.

Q12

¿Qué conocimientos nuevos adquiriste y cómo los explicarías a otra persona?

Adquirí el dominio práctico del despliegue continuo en la nube. Lo explicaría diciendo que HTML es la pared de una casa, CSS es la pintura y decoración, y Render es la dirección de la calle que le das a las visitas para que puedan encontrar tu casa en el mundo.
